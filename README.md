# Worship room media

Folder names match the door plates. Each folder is kept in GitHub by its
`media-slots.txt` file, even before you add any images.

Add these five files to every worship-room folder:

```text
main.jpg
left.jpg
left-2.jpg
right.jpg
right-2.jpg
```

`main.jpg` is the large 16:9 frame on the back wall. The other four files are
the two portrait frames on the left wall and the two portrait frames on the
right wall.

Door order:

1. `BOOT WORSHIP` -> `boot-worship`
2. `ASS WORSHIP` -> `ass-worship`
3. `TIT WORSHIP` -> `tit-worship`
4. `GODDESS WORSHIP` -> `goddess-worship`
5. `CHASTITY / DENIAL` -> `chastity-denial`
6. `LATEX / SHINY WORSHIP` -> `latex-shiny-worship`
7. `FEET / TOE WORSHIP` -> `feet-toe-worship`
8. `FACE WORSHIP` -> `face-worship`
9. `PEGGING / STRAP-ON` -> `pegging-strap-on`
10. `LEGS / THIGH WORSHIP` -> `legs-thigh-worship`

The default media type is `image`. To use video or GIF media, change that
slot's `type` and file extension in `index.html`.
